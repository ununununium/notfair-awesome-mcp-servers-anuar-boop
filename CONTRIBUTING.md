# Contributing

Thanks for your interest in contributing!

## Adding a New Server

1. Fork this repository
2. Add your server to the appropriate category in `README.md`
3. Use the format: `- [Name](link) - Short description.`
4. Submit a pull request

## Guidelines

- The server must be open source
- The description should be concise (one line)
- Check for duplicates before submitting
- Place entries in alphabetical order within categories
- Include a working link to the repository

## Quality Standards

- The project should have a README
- The project should be actively maintained
- The project should actually implement the MCP protocol
